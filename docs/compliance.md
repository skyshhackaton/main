# Compliance and Safety Notes

## 핵심 원칙

- 투자 추천, 투자 자문, 수익 보장을 제공하지 않습니다.
- 사용자의 API Key 또는 Secret Key를 서버에 저장하지 않습니다.
- MVP는 업비트 공개 Quotation API만 사용합니다.
- 개인정보를 수집하지 않습니다.
- 점수는 시장 상태 관찰값으로만 설명합니다.

## 금지 표현

다음 표현은 사용하지 않습니다.

- 지금 사세요
- 지금 파세요
- 매수 기회입니다
- 매도 신호입니다
- 7일 뒤 수익률이 높습니다
- 손실을 피할 수 있습니다
- 수익을 보장합니다

## 권장 표현

다음처럼 현재 상태와 성찰 질문 중심으로 표현합니다.

- 매수 심리와 FOMO 조짐이 우세한 상태입니다.
- 과열과 추격매수 심리가 강한 상태입니다.
- 이 수치는 시장 상태 관찰을 위한 참고값입니다.
- 지금 판단의 근거가 정보인지 감정인지 확인해보세요.
- 과거 유사 구간은 참고 사례이며 미래를 보장하지 않습니다.

## UI 상시 문구

본 지수는 업비트 공개 데이터 기반 시장 상태 관찰 도구입니다. 투자 추천, 투자 자문, 수익 보장을 제공하지 않습니다.

## 개발 체크리스트

- [ ] API Key/Secret Key 입력 폼이 없는가?
- [ ] 서버 저장소에 민감 정보가 남지 않는가?
- [ ] 화면 하단 또는 결과 카드에 면책 문구가 보이는가?
- [ ] 등급 설명이 미래 가격을 예측하지 않는가?
- [ ] Historical Mirror가 과거 참고 사례로만 표현되는가?
- [ ] Decision Pause 질문이 매수/매도 지시가 아닌 자기 점검 문장인가?
