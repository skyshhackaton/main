# FOMO Score Backtest Report

## 목적과 범위

FOMO Score의 가중치가 과거 200일에서 어떤 결과를 보이는지 검증한다. 이 분석은 과거 관찰 결과이며 미래 가격 예측, 투자 추천 또는 수익 보장을 의미하지 않는다.

## 평가 방법

- 입력: oldest-first로 정렬된 최소 565개 일봉 캔들
- 점수 계산: 각 시점 `t`마다 `candles[:t+1]`만 사용
- 평가 구간: 0-20, 20-40, 40-60, 60-80, 80-100
- 결과 지표: 각 구간의 7일 후 평균 수익률, 상승 비율, 표본 수
- 경계 처리: 미래 7일 가격이 없는 마지막 7개 점수는 평가에서 제외
- 민감도: X7(거래량)과 X8(연속 상승)을 각각 0.15, 0.20, 0.25로 조합
- 가중치 보정: X7/X8 변경 후 X1-X6의 상대 비율을 유지하며 합계를 1.0으로 조정

## Look-ahead bias 감사

| 대상 | 결과 | 근거 |
|---|---|---|
| `fomo_score.score_series` | 통과 | 시점 `t`에서 `score_at(candles[:t+1])` 호출 |
| `fomo_score._calc_indicators` | 통과 | 전달받은 과거 슬라이스 내부의 trailing window만 사용 |
| `backtest.evaluate_weights` | 통과 | 미래 종가는 점수 계산이 끝난 뒤 평가 라벨에만 사용 |
| `historical_mirror.build_historical_mirror` | 통과 | 과거 점수는 `score_series`로 생성하고 미래 수익률은 과거 유사 사례의 사후 통계에만 사용 |
| `knn_mirror` | 통과 | 각 후보 피처는 해당 시점까지의 가격·거래량만 사용하고, 미래 수익률은 후보 선택 후 사후 통계에만 사용 |
| `forecast_score` | 통과 | 시점 `t`까지의 lag 피처로 `t+h` 점수를 라벨링하며, MAE 평가는 앞 구간 학습·뒤 구간 평가 순서를 유지 |
| `train_knn` | 통과 | `TimeSeriesSplit`을 사용하고 KNN 스케일러를 Pipeline 안에서 fold별 학습하여 검증 구간 정보 유입 방지 |
| `upbit_client` | 해당 없음 | 캔들 수집·정규화·oldest-first 정렬·저장만 수행하며 지표를 계산하지 않음 |
| `data_export` | 해당 없음 | 저장된 캔들의 형식 변환과 내보내기만 수행하며 지표를 계산하지 않음 |
| `main` | 통과 | 점수 및 유사 구간 계산을 검증된 도메인 함수에 위임하고 별도 미래 데이터를 주입하지 않음 |
| 미래 데이터 변경 테스트 | 직접 검증 통과 | 마지막 캔들 변경 시 앞선 모든 점수가 동일한지 테스트로 검증 |
| 운영 산식 동등성 테스트 | 직접 검증 추가 | 기본 가중치 백테스트 시계열이 공개 `score_series` 결과와 완전히 같은지 비교 |

## 구현상 관찰 사항

- X3는 단일 마켓의 상승일 거래량 비율이므로 일반적인 의미의 시장 폭(market breadth)과 다르다. 멀티마켓 도입 시 정의 재검토가 필요하다.
- X6은 전체 가중치의 5%이므로 기여도가 작다. 실데이터 민감도 결과를 본 후 유지 또는 재배분을 결정해야 한다.
- 고탐욕 구간의 평균 7일 수익률이 음수여도 인과관계나 미래 조정을 보장하지 않는다. 표본 수와 상승 비율을 함께 제시해야 한다.
- 민감도 분석은 `fomo_score.WEIGHTS` 전역값을 변경하지 않고 전달된 가중치로 별도 시계열을 계산하므로 API 점수 계산과 동시에 실행돼도 가중치가 섞이지 않는다.
- 모든 분석 API 응답에는 disclaimer가 포함된다. `/api/health`는 상태 확인용 비분석 엔드포인트로 disclaimer가 없으므로, 체크리스트의 "모든 엔드포인트"를 문자 그대로 적용하면 미충족이며 health를 명시적 예외로 정의해야 한다.

## 결론

코드 수준의 look-ahead 방지와 가중치 합계 검증은 통과했다. 다만 실제 세 마켓에서 80점 이상 표본이 전혀 생성되지 않아 “고탐욕 이후 단기 조정”은 판단할 수 없다. X7·X8을 0.15~0.25로 조정해도 결과가 같으므로, 현재 가중치가 타당하다고 결론내리기보다 전체 점수 분포와 정규화 방식 및 등급 임계값을 함께 재검토하는 것이 타당하다. 이 결과는 과거 관찰 통계이며 미래 가격을 예측하거나 투자 행동을 권고하지 않는다.
