# FOMO Score Backtest Report

## 목적과 범위

FOMO Score의 가중치가 과거 200일에서 어떤 결과를 보이는지 검증한다. 이 분석은 과거 관찰 결과이며 미래 가격 예측, 투자 추천 또는 수익 보장을 의미하지 않는다.

## 평가 방법

- 입력: oldest-first로 정렬된 최소 565개 일봉 캔들
- 점수 계산: 각 시점 `t`마다 `candles[:t+1]`만 사용
- 평가 구간: 0-20, 20-40, 40-60, 60-80, 80-100
- 결과 지표: 각 구간의 7일 후 평균 수익률, 상승 비율, 표본 수
- 경계 처리: 미래 7일 가격이 없는 마지막 7개 점수는 평가에서 제외
- 민감도: X7(거래량)과 X8(연속 상승)을 각각 0.15, 0.20, 0.25로 조합
- 가중치 보정: X7/X8 변경 후 X1-X6의 상대 비율을 유지하며 합계를 1.0으로 조정

## Look-ahead bias 감사

| 대상 | 결과 | 근거 |
|---|---|---|
| `fomo_score.score_series` | 통과 | 시점 `t`에서 `score_at(candles[:t+1])` 호출 |
| `fomo_score._calc_indicators` | 통과 | 전달받은 과거 슬라이스 내부의 trailing window만 사용 |
| `backtest.evaluate_weights` | 통과 | 미래 종가는 점수 계산이 끝난 뒤 평가 라벨에만 사용 |
| 미래 데이터 변경 테스트 | 직접 검증 통과 | 마지막 캔들 변경 시 앞선 모든 점수가 동일한지 테스트로 검증 |

## 구현상 관찰 사항

- X3는 단일 마켓의 상승일 거래량 비율이므로 일반적인 의미의 시장 폭(market breadth)과 다르다. 멀티마켓 도입 시 정의 재검토가 필요하다.
- X6은 전체 가중치의 5%이므로 기여도가 작다. 실데이터 민감도 결과를 본 후 유지 또는 재배분을 결정해야 한다.
- 고탐욕 구간의 평균 7일 수익률이 음수여도 인과관계나 미래 조정을 보장하지 않는다. 표본 수와 상승 비율을 함께 제시해야 한다.
