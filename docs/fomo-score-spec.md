# FOMO Score Specification

## 설계 철학

CNN Fear & Greed Index의 시장 심리 지표 구성을 참고하되, 초보 투자자가 실제로 흔들리기 쉬운 신호인 거래량 급증과 연속 상승에 더 큰 가중치를 둡니다.

- 모든 지표는 시점 t와 그 이전 정보만 사용합니다.
- 모든 지표는 0~100으로 정규화합니다.
- 결과는 투자 판단이 아니라 시장 상태 관찰값입니다.

## 입력 데이터

필수 데이터는 업비트 공개 일봉 캔들입니다.

```text
GET https://api.upbit.com/v1/candles/days?market={market}&count=200&to={cursor}
```

필요 필드:

- `trade_price`: 종가
- `opening_price`: 시가
- `high_price`: 고가
- `low_price`: 저가
- `candle_acc_trade_volume`: 거래량
- `candle_date_time_utc`: 캔들 시각

현재 점수 계산에는 최소 365개, 200일 히스토리 계산에는 565개 이상의 일봉 캔들을 수집합니다.

## 지표

| ID | 이름 | 산식 요약 | 가중치 |
|---|---|---|---:|
| X1 | 가격 모멘텀 | 120일 이동평균 대비 현재가 | 10% |
| X2 | 가격 강도 | 365일 고저 범위 내 현재가 위치 | 10% |
| X3 | 시장 폭 | 최근 20일 상승봉 거래량 비율 | 10% |
| X4 | 매수 압력(CLV) | 최근 14일 종가 위치 평균 | 15% |
| X5 | RSI | 14일 RSI | 10% |
| X6 | 변동성 역수 | 최근 20일 수익률 표준편차의 역방향 점수 | 5% |
| X7 | 거래량 모멘텀 | 5일 평균 거래량 / 20일 평균 거래량 | 20% |
| X8 | 연속 상승 | 최근 7일 중 상승 마감일 비율 | 20% |

## 등급

| 점수 | 등급 | 사용자 표현 |
|---:|---|---|
| 0~20 | 극단적 공포 | 시장 불안과 패닉 심리가 강한 상태 |
| 21~40 | 공포 | 하락 우려와 관망 심리가 우세한 상태 |
| 41~60 | 중립 | 특정 방향의 심리 쏠림이 약한 상태 |
| 61~80 | 탐욕 | 매수 심리와 FOMO 조짐이 우세한 상태 |
| 81~100 | 극단적 탐욕 | 과열과 추격매수 심리가 강한 상태 |

미래 가격, 기대수익, 매수/매도 행동을 직접 암시하는 표현은 사용하지 않습니다.
