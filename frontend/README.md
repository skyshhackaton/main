# Frontend

FOMO Break MVP 웹 클라이언트입니다. 별도 빌드 없이 정적 HTML/CSS/JS로 실행합니다.

## 화면 구성

1. Judgment Firewall: 가상 매수/매도 시도를 실제 주문이 아닌 자기 점검 흐름으로 전환
2. Decision Pause 전 가상 시도 화면: 사용자가 가상 매수/매도 버튼을 누른 직후의 장면과 가상 수량 입력을 크게 표시
3. 가상 행동 티켓: 가상 매수/매도 의도를 주문 전송 없이 Decision Pause로 전환
4. Decision Pause 미니 화면: 첫 화면에서 바로 누를 수 있는 자기 점검 체크
5. 공개 데이터 관찰 콘솔: FOMO Score, 표시용 현재가, 과거 참고 사례, 오차 범위, 자기 점검 상태
6. 현재 FOMO Score 카드
7. 구성 요소별 점수 바
8. 판단 준비도 패널
9. 시장 레이더: KRW-BTC, KRW-ETH, KRW-XRP 심리 상태와 표시용 현재가 비교
10. 최근 FOMO Score 흐름 차트
11. Historical Mirror 과거 참고 구간
12. FOMO Score 흐름 참고와 오차 범위 밴드
13. KNN 패턴 참고
14. Decision Pause 체크리스트와 질문
15. 면책 문구

## 실행

백엔드 하나만 실행해도 API와 화면을 함께 확인할 수 있습니다.

```powershell
cd C:\Coding\2026SKYSH\main\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 엽니다.

```text
http://127.0.0.1:8000
```

8000 포트가 이미 사용 중이면 다른 포트로 실행합니다.

```powershell
cd C:\Coding\2026SKYSH\main\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

이 경우 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8765
```

프론트엔드만 따로 띄우고 싶다면 다른 터미널에서 정적 서버를 실행합니다.

```powershell
cd C:\Coding\2026SKYSH\main\frontend
python -m http.server 5173
```

이 경우에도 프론트는 기본적으로 `http://127.0.0.1:8000` API를 호출합니다.

```text
http://127.0.0.1:5173
```

## MVP 차별화

이 UI는 점수만 크게 보여주는 대시보드가 아니라, `Judgment Firewall`, `시장 레이더`, `오차 범위`, `과거 유사 구간`, `Decision Pause 체크리스트`를 한 화면에 묶어 사용자가 감정적 판단 전에 근거를 점검하도록 설계했습니다.

- 첫 화면은 가상 주문 입력, 주문 API 미사용 상태, 공개 데이터 확인, Decision Pause 전환 과정을 한 화면에서 확인하도록 구성했습니다.
- Judgment Firewall은 가상의 행동 시도를 실거래로 연결하지 않고 `시도 인식 -> 실거래 차단 -> 근거 분리 -> 일시정지`로 전환합니다.
- Decision Pause 전 가상 시도 화면은 `가상 매수 화면`, `가상 매도 화면`, 가상 수량 입력, `주문 전송 전 차단` 로그를 첫 화면에서 크게 보여줍니다.
- 공개 데이터 관찰 콘솔은 첫 화면에서 현재 점수, 표시용 현재가, 과거 참고 사례, 오차 범위를 함께 보여주는 실제 사용 장면입니다.
- 가상 행동 티켓은 매수/매도처럼 보이는 의도 화면을 보여주되, 실제 주문 전송 없이 `Decision Pause` 전환 버튼으로 흐름을 바꿉니다.
- Decision Pause 미니 화면은 판단 준비도, 체크 상태, 근거/시점/범위/시간 설명을 함께 보여주며, 첫 화면에서 바로 자기 점검이 작동하는 모습을 보여줍니다.
- 첫 화면의 공개 데이터 흐름과 Decision Pause 설명은 녹화 화면 안에서 잘리지 않도록 축약 문구로 표시하고, 상세 문장은 하단 체크리스트에 유지합니다.
- 판단 준비도는 숫자와 원형 진행률을 함께 표시해 0~100 기준으로 어느 정도 채워졌는지 직관적으로 확인할 수 있습니다.
- 시장 레이더는 세 마켓의 심리 쏠림이 동조인지 분산인지 보여주며, 현재가는 표시용 live snapshot으로만 사용합니다.
- 오차 범위 밴드는 FOMO Score 참고값을 방향으로 단정하지 않도록 돕습니다.
- KNN 패턴 참고는 현재 흐름과 닮았던 과거 분포를 보여주며 미래를 보장하지 않습니다.
- Decision Pause 체크리스트는 사용자의 선택을 저장하지 않고 현재 화면의 판단 준비도에만 반영합니다.

## 2분 시연 영상 흐름

권장 녹화는 90초 안팎, 1080p 30fps 기준입니다. 이 설정이면 보통 1GB 제한 안에 충분히 들어갑니다. 화면의 `90초 가이드 시작` 버튼을 누르면 발표 속도에 맞춰 단계가 천천히 전환됩니다.

1. 0~15초: `http://127.0.0.1:8000`에서 API 연결 상태와 선택 마켓을 보여줍니다.
2. 15~35초: `가상 매수 시도`를 누르고 가상 수량을 입력한 뒤 `가상 주문 전송 시도` 또는 `주문 전송 없이 Decision Pause 열기`를 눌러 차단 로그와 자기 점검 전환을 보여줍니다.
3. 35~55초: FOMO Score, 과거 참고 구간, 오차 범위, 표시용 현재가가 함께 묶여 나오는 근거 영역을 보여줍니다.
4. 55~75초: `가상 매도 시도`를 눌러 매도 의도도 같은 차단과 자기 점검 흐름으로 전환되는 것을 보여줍니다.
5. 75~90초: Decision Pause 체크리스트와 하단 면책 문구를 보여주며 입력값이 저장/전송되지 않고 API Key 입력, 실거래 연결이 없음을 말합니다.
