# Frontend

FOMO Break MVP 웹 클라이언트입니다. 별도 빌드 없이 정적 HTML/CSS/JS로 실행합니다.

## 화면 구성

1. 첫 화면: 가상 매수/매도 선택, 가상 수량 입력, 전송 시도 차단, Decision Pause 슬라이드
2. 공개 데이터 관찰: FOMO Score, 표시용 현재가, 과거 참고 사례, 오차 범위 요약
3. 시장 레이더: KRW-BTC, KRW-ETH, KRW-XRP 심리 상태와 표시용 현재가 비교
4. 현재 FOMO Score와 판단 준비도 패널
5. 최근 FOMO Score 흐름 차트
6. Historical Mirror 과거 참고 구간
7. FOMO Score 흐름 참고와 오차 범위 밴드
8. KNN 패턴 참고
9. Decision Pause 상세 체크리스트와 면책 문구

## 실행

백엔드 하나만 실행해도 API와 화면을 함께 확인할 수 있습니다.

```powershell
cd C:\Coding\2026SKYSH\main\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 엽니다.

```text
http://127.0.0.1:8000
```

8000 포트가 이미 사용 중이면 다른 포트로 실행합니다.

```powershell
cd C:\Coding\2026SKYSH\main\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

이 경우 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8765
```

프론트엔드만 따로 띄우고 싶다면 다른 터미널에서 정적 서버를 실행합니다.

```powershell
cd C:\Coding\2026SKYSH\main\frontend
python -m http.server 5173
```

이 경우에도 프론트는 기본적으로 `http://127.0.0.1:8000` API를 호출합니다.

```text
http://127.0.0.1:5173
```

## MVP 차별화

이 UI는 점수만 크게 보여주는 대시보드가 아니라, 가상 행동을 실제 주문으로 보내기 전에 공개 데이터 확인과 자기 점검으로 전환하는 사용 흐름을 보여줍니다.

- 첫 화면은 가상 행동 선택, 가상 수량 입력, 차단 로그, Decision Pause 슬라이드만 남겨 처음 보는 사용자도 눌러야 할 순서를 바로 볼 수 있게 했습니다.
- 가상 매수/매도 카드는 크게 배치하고, 선택 후 `가상 주문 전송 시도`를 누르면 실제 주문 API 호출 없이 차단 로그와 자기 점검으로 이동합니다.
- Decision Pause는 한 문항씩 넘기는 슬라이드 방식이며, 확인 버튼을 누르면 다음 문항으로 넘어갑니다.
- 공개 데이터 관찰 콘솔은 첫 화면에서 현재 점수, 표시용 현재가, 과거 참고 사례, 오차 범위를 짧은 요약으로 보여줍니다.
- 보조 설명 블록은 첫 화면에서 숨겨 정보량을 줄이고, 상세 설명은 하단 패널과 발표 멘트에서 다룹니다.
- 판단 준비도는 숫자와 원형 진행률을 함께 표시해 0~100 기준으로 어느 정도 채워졌는지 직관적으로 확인할 수 있습니다.
- 시장 레이더는 세 마켓의 심리 쏠림이 동조인지 분산인지 보여주며, 현재가는 표시용 live snapshot으로만 사용합니다.
- 오차 범위 밴드는 FOMO Score 참고값을 방향으로 단정하지 않도록 돕습니다.
- KNN 패턴 참고는 현재 흐름과 닮았던 과거 분포를 보여주며 미래를 보장하지 않습니다.
- Decision Pause 체크리스트는 사용자의 선택을 저장하지 않고 현재 화면의 판단 준비도에만 반영합니다.

## 2분 시연 영상 흐름

권장 녹화는 90초 안팎, 1080p 30fps 기준입니다. 이 설정이면 보통 1GB 제한 안에 충분히 들어갑니다. 화면의 `90초 가이드 시작` 버튼을 누르면 발표 속도에 맞춰 단계가 천천히 전환됩니다.

1. 0~15초: `http://127.0.0.1:8000`에서 API 연결 상태와 선택 마켓을 보여줍니다.
2. 15~35초: `가상 매수 시도`를 누르고 가상 수량을 입력한 뒤 `가상 주문 전송 시도` 또는 `점검 열기`를 눌러 차단 로그와 자기 점검 전환을 보여줍니다.
3. 35~55초: FOMO Score, 과거 참고 구간, 오차 범위, 표시용 현재가가 함께 묶여 나오는 근거 영역을 보여줍니다.
4. 55~75초: `가상 매도 시도`를 눌러 매도 의도도 같은 차단과 자기 점검 흐름으로 전환되는 것을 보여줍니다.
5. 75~90초: Decision Pause 슬라이드를 넘기고 하단 면책 문구를 보여주며 입력값이 저장/전송되지 않고 API Key 입력, 실거래 연결이 없음을 말합니다.
