# Frontend

FOMO Break MVP 웹 클라이언트입니다. 별도 빌드 없이 정적 HTML/CSS/JS로 실행합니다.

## 화면 구성

1. 첫 화면: `행동 선택 -> 데이터 확인 -> 자기 점검 -> 마무리` 단계형 플로우
2. 가상 행동: 가상 매수/매도 선택, 가상 수량 입력, 전송 시도 차단
3. 공개 데이터 확인: 전송 시도 이후 FOMO Score, 표시용 현재가, 과거 참고 사례, 오차 범위 요약 표시
4. Decision Pause: 공개 데이터 확인 완료 이후 한 문항씩 넘기는 자기 점검 슬라이드 표시
5. 판단 근거 정리: 점검 마침 이후 최종 정리와 보고서 이동 버튼 표시
6. 보고서 파트: 사용자가 `보고서 파트 보기`를 열 때만 시장 레이더, 점수 흐름, 과거 참고 사례, KNN 패턴, 상세 체크리스트 표시

## 실행

백엔드 하나만 실행해도 API와 화면을 함께 확인할 수 있습니다.

```powershell
cd C:\Coding\2026SKYSH\main\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 엽니다.

```text
http://127.0.0.1:8000
```

8000 포트가 이미 사용 중이면 다른 포트로 실행합니다.

```powershell
cd C:\Coding\2026SKYSH\main\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

이 경우 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8765
```

프론트엔드만 따로 띄우고 싶다면 다른 터미널에서 정적 서버를 실행합니다.

```powershell
cd C:\Coding\2026SKYSH\main\frontend
python -m http.server 5173
```

이 경우에도 프론트는 기본적으로 `http://127.0.0.1:8000` API를 호출합니다.

```text
http://127.0.0.1:5173
```

## MVP 차별화

이 UI는 점수만 크게 보여주는 대시보드가 아니라, 가상 행동을 실제 주문으로 보내기 전에 공개 데이터 확인과 자기 점검으로 전환하는 사용 흐름을 보여줍니다.

- 첫 화면은 가상 행동 선택과 가상 수량 입력만 먼저 보여주고, 사용자가 단계를 완료할 때마다 다음 UI를 열어 처음 보는 사용자도 순서를 놓치지 않게 했습니다.
- 1단계 전송 시도 이후에만 2단계 공개 데이터 확인을 보여주고, 공개 데이터 확인 완료 이후에만 안전 경로와 Decision Pause를 보여줍니다.
- 가상 매수/매도 카드는 크게 배치하고, 선택 후 `전송 시도`를 누르면 실제 주문 API 호출 없이 차단 로그와 공개 데이터 확인으로 이동합니다.
- 안전 경로의 `Decision Pause로 이동` 버튼은 공개 데이터 확인 완료 후 활성화되며, 실제 주문 전송 없이 자기 점검으로만 이동합니다.
- Decision Pause는 한 문항씩 넘기는 슬라이드 방식이며, 확인 버튼은 체크 해제가 아니라 확인 완료로만 처리됩니다.
- `점검 마침`을 누르면 4개 문항을 모두 확인하지 않았더라도 판단 근거 정리 단계로 이동합니다.
- 판단 근거 정리 패널은 안전 경로와 Decision Pause 옆에 표시되며, 상세 지표는 `자세한 분석은 보고서를 확인하세요` 버튼으로 분리합니다.
- 공개 데이터 관찰 콘솔은 첫 화면에서 현재 점수, 표시용 현재가, 과거 참고 사례, 오차 범위를 짧은 요약으로 보여줍니다.
- 공개 데이터 카드의 배경은 왼쪽부터 차오르는 정도로 FOMO Score, 표시용 현재가 등락 강도, 과거 참고 시점의 오래된 정도, 오차 범위의 작고 큼을 직관적으로 보여줍니다.
- 차트, 시장 레이더, 과거 상세, KNN 패턴, 상세 체크리스트는 기본 화면에서 숨기고 `보고서 파트 보기`를 열 때만 표시합니다.
- 긴 문구가 버튼과 카드 밖으로 삐져나오지 않도록 첫 화면 컴포넌트는 고정 높이보다 반응형 grid와 줄바꿈 가능한 텍스트를 우선합니다.
- 판단 준비도는 숫자와 원형 진행률을 함께 표시해 0~100 기준으로 어느 정도 채워졌는지 직관적으로 확인할 수 있습니다.
- 시장 레이더는 세 마켓의 심리 쏠림이 동조인지 분산인지 보여주며, 현재가는 표시용 live snapshot으로만 사용합니다.
- 오차 범위 밴드는 FOMO Score 참고값을 방향으로 단정하지 않도록 돕습니다.
- KNN 패턴 참고는 현재 흐름과 닮았던 과거 분포를 보여주며 미래를 보장하지 않습니다.
- Decision Pause 체크리스트는 사용자의 선택을 저장하지 않고 현재 화면의 판단 준비도에만 반영합니다.

## 2분 시연 영상 흐름

권장 녹화는 90초 안팎, 1080p 30fps 기준입니다. 이 설정이면 보통 1GB 제한 안에 충분히 들어갑니다. 화면의 `90초 시연` 버튼을 누르면 발표 속도에 맞춰 단계가 천천히 전환됩니다.

1. 0~15초: `http://127.0.0.1:8000`에서 API 연결 상태와 선택 마켓을 보여줍니다.
2. 15~35초: `가상 매수`를 선택하고 가상 수량을 입력한 뒤 `전송 시도`를 눌러 차단 로그와 자기 점검 전환을 보여줍니다.
3. 35~55초: FOMO Score, 표시용 현재가, 과거 참고, 오차 범위가 공개 데이터 확인 단계로 묶여 나오는 것을 보여줍니다.
4. 55~75초: Decision Pause 문항을 하나씩 확인하며 판단 준비도와 단계 표시가 바뀌는 장면을 보여줍니다.
5. 75~90초: `보고서 파트 보기`를 열어 상세 분석은 옵션으로 분리되어 있음을 보여주고, API Key 입력과 실거래 연결이 없음을 말합니다.
